# GameGuru

In-game overlay for FPS, temperatures, latency and HUD widgets.

[gameguru.app](https://gameguru.app) · [Releases](https://github.com/gimzdev/gameguru/releases) · React · Electron · OpenGL


GameGuru is an overlay that sits on top of whatever you play and shows what you would otherwise alt-tab
for: frame rate, temperatures, latency and your own notes. It finds the game by itself and stays out of
the way until you ask for more.

| | |
|:---|:---|
| **Performance** | FPS, CPU and GPU load, temperatures, latency |
| **HUD widgets** | Timers, counters and notes, on hotkeys |
| **Streaming** | Chat, alerts, now playing, OBS |
| **Works with** | DirectX, OpenGL and Vulkan, in full screen or windowed |
